# AngelaCam

简洁好用的 Android 原生相机 App，Kotlin + CameraX。

## 功能

- 拍照：闪光灯（自动/开/关）、延时自拍（3s/10s）
- 录像：补光灯、录制计时、后台保持亮屏
- 前后摄像头切换
- 双指缩放、点按对焦/测光（带对焦框动画）
- 曝光补偿（EV 调节）
- 九宫格构图辅助线
- 音量键快门
- 自带相册：网格浏览、查看大图/播放视频、删除、分享

## 隐私（最小权限原则）

- **相机**：必需，启动时申请
- **麦克风**：只在用户第一次按下录像键时按需申请；拒绝则静音录制，不阻断使用
- **不申请**：位置、存储读取、通讯录等任何其他权限
- **无网络权限**：Manifest 不声明 `INTERNET`，App 没有任何上传数据的能力
- **不写 GPS**：照片 EXIF 不包含位置信息
- **自带相册只收录本应用拍摄的内容**：通过内部记录索引，不扫描用户相册

## 构建

- Android Studio 打开本目录，Run 即可（JDK 17）
- GitHub Actions：每次推送到 `main` 自动构建 debug APK，并发布到 `dev-latest` 预发布
